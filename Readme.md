# YelpCamp

網頁連結： https://yicamp.onrender.com/

練習使用與了解網頁全端的技術包含了 CRUD、Restful 以及串接 map功能 API，架設webServer。

功能介紹：
Guest 可以瀏覽露營營地地圖

使用註冊登入功能後可以進行留言評論

也可以新增露營地點

使用技術：

HTML5 ： 用於創建網頁和網路應用程式的標記語言

CSS3 ： 用於描述以標記語言編寫的文件的呈現方式

Bootstrap ： 免費且開源的前端網頁框架，用於快速設計網站和網頁應用程式

jQuery ： 跨平台的JavaScript庫，在簡化HTML的客戶端腳本處理

DOM操作 ： 一個平台和語言中立的接口，允許程序和腳本動態訪問和更新文檔的內容、結構和樣式

Node.js ： 開源的跨平台JavaScript運行時環境，用於在伺服器端執行JavaScript代碼

Express.js ： 用於建立網頁應用程式和API，並連接中介軟體

REST ： 代表性狀態轉移（REST）是一種開發Web服務的架構風格

MongoDB ： 開源的跨平台文檔導向NoSQL資料庫程式，用於存儲用戶信息、露營地信息和評論

Render ： 雲端部署平台，可用於託管Node.js應用程式並自動處理佈署與擴展
